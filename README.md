## 🔹 Multi-Country Validation Automation
Automated validation of business-registration data against official government registries across multiple European markets.
- Extracts, reconciles and auto-populates records; flags mismatches for review
- **~96% accuracy** on a benchmarked test set; replaced a ~6-minute manual process
- **Stack:** AI agents, Python, Selenium/Playwright, Excel

## 🔹 Validation & Reporting Automation Suite
End-to-end validation + reporting across ~17 data sources with fuzzy-logic and AI-assisted checks.
- **~97% automated**, 0 errors; handling time cut from minutes to seconds
- **Stack:** Tampermonkey/JS, AI agents, Excel, BI dashboards

## 🔹 Audit & Data-Integrity Dashboard
A reconciliation/audit workflow that ingests documents, auto-extracts and reconciles key fields, and surfaces data-quality and exposure risks per case.
- Produced the reporting behind corrective actions
- **Stack:** Python, Flask, Excel, HTML dashboards
- Interactive demo: [Compliance Audit & Exceptions Dashboard ↗](https://jithinjolly2000-maker.github.io/compliance-audit-dashboard/)
